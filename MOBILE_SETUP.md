# ESUG 2027 — Ember + Capacitor mobile app

Ember app (`ember-cli` + Vite) wrapped with Capacitor for iOS and Android.
App ID: `org.esug.app2027`.

## Prerequisites

- Node.js >= 20.19
- For iOS builds: a Mac with Xcode + CocoaPods (`sudo gem install cocoapods`)
- For Android builds: Android Studio + an installed SDK/emulator

## First-time setup

```bash
npm install
```

## Day-to-day web development

```bash
npm start        # runs the Ember dev server at http://localhost:4200
npm run lint
npm test
```

## Building for iOS / Android

Capacitor serves the _built_ Ember app (`dist/`), not the dev server, so any
time you change app code you need to rebuild and re-sync before testing on
device/simulator:

```bash
npm run cap:sync     # ember/vite build -> npx cap sync (copies dist into ios/ and android/)
npm run cap:ios       # sync + open the Xcode project
npm run cap:android   # sync + open the Android Studio project
```

From Xcode or Android Studio you run/debug on a simulator, emulator, or a
connected device as normal.

## Live reload on device (optional)

For faster iteration, point Capacitor at the running Ember dev server instead
of the static build, by temporarily adding to `capacitor.config.js`:

```js
server: {
  url: 'http://<your-machine-ip>:4200',
  cleartext: true,
}
```

Remove this before shipping a build — production builds must serve the
bundled `dist/` assets, not a dev server URL.

## Project layout

- `app/`, `config/`, `tests/` — standard Ember app
- `capacitor.config.js` — Capacitor config (app id, name, web dir)
- `ios/` — generated Xcode project (native shell)
- `android/` — generated Android Studio/Gradle project (native shell)

`ios/` and `android/` are checked in (they're where you add platform-specific
config, icons, splash screens, and native plugins), but their build
artifacts (Pods, Gradle caches, `public/` webview assets) are gitignored
since they're regenerated by `cap sync`.

## Adding native functionality

Capacitor plugins (camera, push notifications, geolocation, filesystem,
etc.) are npm packages, e.g.:

```bash
npm install @capacitor/push-notifications
npx cap sync
```

See https://capacitorjs.com/docs/apis for the plugin catalog.

## App icon

`resources/icon.png` is the source icon (the ESUG 2027 logo flattened onto
its own navy background — app icons can't have transparency). To regenerate
the native icon sets after changing it:

```bash
npm install
npm run generate:icons
```

This uses [`@capacitor/assets`](https://github.com/ionic-team/capacitor-assets)
to regenerate `ios/App/App/Assets.xcassets/AppIcon.appiconset` (and, once you
add the Android platform, its icon set too). Re-run `npm run cap:sync` /
rebuild in Xcode afterwards to see the change on device.

The browser favicon and "Add to Home Screen" icon (`public/favicon.png`,
`public/apple-touch-icon.png`) are generated from the same source but aren't
covered by that script — regenerate them manually if the logo changes.
